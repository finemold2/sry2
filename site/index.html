WHY SRY

타협하지 않은
여섯 가지.

01

진짜 RTF 위에서

정본은 실제 .rtf입니다. 한글·유니코드·각주·인라인 이미지까지 왕복 보존 — Word·한글에서 바로 열립니다.

02

서버 없음 · 완전 오프라인

모든 처리는 브라우저 안에서. 네트워크조차 필요 없습니다. PWA로 설치하면 비행기 안에서도 그대로.

03

원고 안전이 최우선

자동 저장, 저장 검증, 롤링 zip 백업, 다중 탭 동기화. 데스크톱 Scrivener 호환 .scriv로 언제든 꺼낼 수 있습니다.

04

창작 도구 2,445+

분석기·단어 은행·아이디어 생성기·작법 가이드·절차적 합성기. 막혔을 때 곁에 두는, 거의 앱 한 개 규모의 대형 도구 100종도 함께.

05

설치 없이, 지금 바로

내려받을 것도, 복잡한 설정도 없습니다. 브라우저 새 탭 하나로 첫 문장을 시작하세요. 계정은 선택입니다.

06

모든 글쓰기를 위해

웹소설 연재부터 소설·논픽션·학술논문·에세이·블로그·각본·시까지. 유형을 고르면 그에 맞는 템플릿과 도구가 준비됩니다.

당신의 것입니다.

글은 당신의 기기에만 머뭅니다. 우리는 그것을 볼 수도, 가질 수도 없습니다. 그럼에도 잃지 않도록, 여러 겹의 안전장치를 겹쳐 두었습니다.

  • 브라우저 로컬 저장IndexedDB · File System Access. 업로드 없음.
  • 자동 저장 & 저장 검증변경 후 지정 간격 저장. 쓴 데이터를 되읽어 확인.
  • 롤링 zip 백업최근 15개 자동 백업. 무결성 확인 후 복원.
  • 표준 .scriv 패키지데스크톱 Scrivener 3와 호환. 언제든 이주 가능.
  • 다중 탭 동기화여러 탭·창에서 열어도 실시간 반영, 손실 경고.
  • 구조 복구손상된 인덱스를 감지·복구하는 안전 경로.
