# sry (임시 명칭)

[Scrivener](https://www.literatureandlatte.com/scrivener/)의 핵심 글쓰기 경험을 재현한 **브라우저 전용(서버 없음)** 웹앱입니다.
모든 문서 본문은 **실제 `.rtf` 파일로 저장되고, 작성도 RTF 모델 위에서 이뤄집니다.** 한글/유니코드를 완전히 지원합니다.

## 핵심 설계

Scrivener와 동일하게 **구조(인덱스)와 본문(.rtf)을 분리**합니다.

- `project.json` — 바인더 트리, 메타데이터, 라벨/상태/키워드, 스냅샷 등 인덱스
- `Files/<UUID>.rtf` — 각 텍스트 문서의 본문(진짜 RTF)

본문의 정본(canonical) 포맷은 RTF이며, 편집은 브라우저 contenteditable(HTML)에서 하고 저장 시 자체 **HTML↔RTF 변환 엔진**으로 왕복합니다. 적절한 브라우저용 RTF 라이브러리가 없어 직렬화기·파서를 직접 구현했습니다.

## 기능

- **바인더**: 폴더/텍스트 계층 트리, 3대 고정 루트(원고·자료·휴지통), 드래그 재정렬·재배치, 인라인 이름변경, 컨텍스트 메뉴, 휴지통/완전삭제
- **에디터**: 굵게·기울임·밑줄·취소선, 글꼴·크기·글자색·형광펜, 정렬, 제목/인용 스타일, 글머리/번호 목록, 하이퍼링크
- **Scrivenings**: 폴더 선택 시 하위 문서를 연속 편집 · **분할 에디터**(좌우/상하 두 문서 동시 편집) · **타자기 스크롤**(캐럿 줄 중앙 고정)
- **문서 템플릿**: 캐릭터/장소 **스케치 시트**(스크리브너식) + **구조화 캐릭터·장소 카드**(폼 입력 → 본문 RTF 자동 생성)
- **북마크**: 문서/프로젝트 북마크(내부 문서·URL), **문서 이동 히스토리**(뒤로/앞으로, Alt+←/→), 사용자 지정 아이콘, **스크래치패드**(전역 빠른 메모)
- **코르크보드**: 인덱스 카드(제목+시놉시스), 드래그 재정렬, **정렬(제목/라벨/상태/수정일/단어수)·카드 크기 조절**, 라벨/상태 표시
- **아웃라이너**: 트리-테이블, **표시 컬럼 선택기(작성일·수정일·글자수 등)·헤더 클릭 정렬**, 인라인 편집, 단어수 롤업
- **칸반 보드**: 문서를 **상태/라벨별 열**로 표시, 카드를 드래그해 상태·라벨 변경, 열별 새 문서 추가 (⌘4)
- **인스펙터**: 시놉시스, 문서/프로젝트 노트, 메타데이터(라벨·상태·섹션타입·페이지나눔·커스텀필드·목표), 키워드, **코멘트·각주 탭**, **참조(내부 링크/백링크)**, 스냅샷(비교 diff 포함)
- **코멘트·각주·미주**: 본문 인라인 마커 삽입, 인스펙터에서 편집/삭제/이동, **실제 RTF `\footnote`/`\*\annotation` 으로 왕복 저장**, 컴파일 출력 반영
- **내부 문서 링크/백링크**: 문서 간 Scrivener 링크(`scriv://`) 삽입·클릭 이동, 인스펙터 백링크 패널
- **각본 모드**: Tab 으로 요소 순환(장면·지문·인물·대사·괄호·전환), Enter 자동 전환, **Fountain·FDX 가져오기**
- **미디어**: 이미지·PDF 바인더 아이템(IndexedDB blob + 뷰어), **에디터 인라인 이미지(RTF `\pict` 왕복)**, **DOCX 가져오기(mammoth)**
- **목표/통계**: 문서·세션·원고 단어 목표와 진행 막대, 프로젝트 통계(페이지·읽기시간·단어빈도·집필 히트맵), 글쓰기 스타일 분석
- **검색/컬렉션**: 전체 텍스트 검색(범위·연산자·옵션), 표준+검색 컬렉션, 컬렉션 탭
- **문서 재구성**: 분할(⌘⇧K)·병합·그룹/해제·복원·이동, 문서 내 찾기·바꾸기(⌘F), 프로젝트 전체 치환
- **템플릿·이름 생성기 · AI 어시스턴트(BYO-key)**: 장르별 새 프로젝트 템플릿, 한/영 이름 생성, 사용자 API 키로 요약·이어쓰기·교정(서버 없음)
- **창작 도구**: **플롯/서사 구조 템플릿 91종**(3막·영웅서사·세이브더캣·시드 필드·맥키 스토리·요크 5막·보글러 여정·트루비 22단계·스토리서클·기승전결 등 국내외 작법서의 검증된 골격을 폴더·장면으로 일괄 생성), 라이팅 프롬프트 글감 덱, 언어 초점(대사·부사·수동태 하이라이트), 장면 긴장도 곡선(텐션 아크)
- **🕸 스토리 캔버스 (⌘5)** — **옵시디언 Canvas 동일** 무한 캔버스:

## RTF 엔진

- 한글 등 비ASCII는 `\uN?`(부호 있는 16비트 UTF-16 코드유닛)로 인코딩, 서로게이트 쌍/이모지 지원, `\uc1` 폴백
- 폰트 테이블(`\fcharset129` 한글 기본), 색상 테이블, 스타일시트
- 파서: 토크나이저 + 상태스택, `fonttbl`/`colortbl`/`stylesheet`/하이퍼링크 필드 처리, 미지원 `{\*\...}` 데스티네이션 스킵
- **각주/미주(`\footnote`/`\ftnalt`), 코멘트(`\*\annotation`/`\*\atnid`), 인라인 이미지(`\pict` PNG/JPEG), 들여쓰기·줄간격·페이지나눔** 왕복
- 외부 Word/한글 생성 RTF도 파싱(일반 텍스트·서식·`\uN`·`\'XX`)

테스트: `npm test` — RTF 엔진 라운드트립/보안/견고성 88개 + 내보내기(EPUB/ODT/LaTeX/Markdown) 회귀 12개 + 창작 분석 엔진 55개 = 총 155개

## 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 정적 빌드 -> dist/
npm run preview  # 빌드 미리보기
npm test         # 전체 단위 테스트(RTF 엔진 + 내보내기)
npm run typecheck # 타입 검사
```

`example.rtf`는 엔진이 생성한 샘플로, Microsoft Word / 한글(HWP)에서 바로 열어 확인할 수 있습니다.

## 품질/QA

전 영역을 다중 에이전트 테스터 팀으로 감사하고 확정 버그를 적대적으로 검증·수정했습니다. 대표 수정:
- RTF 파서: 각주/주석 **중첩 서식 그룹 조각화** 해결(`destOwner` 소유자 그룹에서만 commit), `\bin` 바이너리 안전 스킵 + 스택 언더플로우 가드, 마커 문단의 hr 오분류 방지
- 모델: `createItem` 이 확장 필드(blobId/mime/scriptMode/sectionType…)를 보존하도록 수정(미디어 가져오기 정상화)
- 스토어: 삭제된 활성 문서에 대한 **유령 아이템 저장** 방지(널 가드), 삭제 시 미디어 blob 고아 정리(참조 카운팅), 휴지통 아이템 컬렉션 노출 가드, 집필량 기준선 동기화
- 미디어 blob 을 **`.scriv`/zip/백업에 base64 로 인라인**하여 백업 복원·기기 이전 시 보존
- 메뉴 동시 다중 오픈 해결(단일 열림 상태), 모달 **단일 활성화 + ESC/포커스 트랩/ARIA**(공통 `useModal`)
- 좁은 화면 자동 패널 접기가 사용자 토글과 충돌하지 않도록 override, 아웃라이너 sticky 헤더 겹침·컴파일 대화상자 좁은 화면 레이아웃·색 대비(세피아 muted/placeholder) 개선

### 추가 적대적 감사(4차 패스, 24건 확정 수정)

전 서브시스템을 보완 각도로 재감사하고 각 확정 버그를 회귀 테스트로 고정했습니다.

- **보안(신뢰 불가 입력)**: 외부 RTF 폰트명/색 등 CSS 값을 style 속성에서 이스케이프(`escapeAttr`)하고 폰트명을 정화(`\p{Cc}`+위험문자 제거)해 **contenteditable XSS** 차단, 하이퍼링크/이미지 `href·src` 의 `javascript:`/`vbscript:`/`data:` 스킴 무력화(`data:image/`·`scriv://` 는 허용)
- **DoS/견고성**: RTF 파서 **그룹 스택 깊이 상한(4096)** 으로 악성 `{` 폭주 OOM 방지, RTF 가져오기 크기 가드(FS·입력 경로 모두 바이트 기준 통일), `.scriv.zip`/ZIP 가져오기에 **항목 수·압축 해제 누적 바이트 상한**(zip bomb 방어)
- **내보내기 정확성**: EPUB `nav.xhtml` 이 비연속 제목 레벨에서도 **well-formed XML** 보장(들여쓰기 추적), ODT 제목/인용/목록의 명시적 정렬 보존, LaTeX `\href` 의 `&` 이스케이프, Markdown URL 의 `)` 이스케이프·왕복 복원
- **RTF 왕복 충실도**: HTML↔RTF **중첩 목록**(listLevel) 보존, 평범한 링크가 왕복 시 밑줄을 얻지 않도록(`\ulnone`), `colortbl` 마지막 `;` 누락 시 색 복구
- **데이터 무결성**: `.scrivx` 가져오기에서 UUID 누락/중복 시 **키 충돌로 인한 아이템 유실** 방지(새 id 부여), 미디어 저장 실패 시 인라인 데이터 유지, `splitDocument`/`duplicateItem`/스냅샷 롤백의 `scriptMode`·북마크·`plainText` 캐시 보존, 영구 삭제 시 `selectedIds` 정리
- **검증**: 타입체크·전체 단위 테스트(155개 단언)·정적 빌드 통과 + 실제 브라우저(CDP) 부팅·전 도구 렌더 스모크 테스트 확인

### 창작 스튜디오 대규모 확장 + 실사용자 베타

현존 글쓰기 프로그램·작법서를 조사해 도구·틀·템플릿을 데이터화하고, 추가 창작 도구를 더해 **창작 스튜디오를 432개 도구**(분석 54 + 단어은행 94 + 생성기 151 + 가이드 133)로 확장했습니다. 데이터 기반 도구는 `WordBank`/`Generator`/`Guide` 인터페이스 + 레지스트리로 구성해 제네릭 패널이 자동 렌더·검색/필터합니다.

- **헤드리스 Chrome(CDP) 실사용자 베타**로 검증: 432개 도구 전부 패널 렌더 성공(예외 0·콘솔 에러 0), 378개 데이터 도구 전부 **빈 칩/빈 생성결과/빈 가이드 없이 실제 내용 출력** + 생성기 재생성 동작 확인
- **사용자 보고 버그 3건 수정·검증**: (1) 한 문서를 편집하면 그 문서가 열려 있는 **모든 곳(퀵 레퍼런스·캔버스 파일 카드·분할 패널)에 실시간 반영**(에디터가 비활성 상태일 때 `bodyRtf` 변경을 다시 로드), (2) **자동 저장 간격 설정**(0.5~10초/끔) + 수동 저장 불필요, (3) **바인더 → 캔버스 드래그앤드롭**(`effectAllowed` 불일치 수정)
- 플롯 구조 **18종** 전수 검증(빈 제목·시놉시스 누락·중복 id 0)

### 범용 글쓰기 스튜디오로 확장 + 실사용자 버그 일괄 수정

- **글쓰기 유형 시스템 + 연재 관리 대시보드(⌘6)** + **유형별 기능 분석기 47종**(웹소설/학술/블로그·SEO/에세이·논픽션/시나리오/범용) 추가 → 창작 스튜디오 **479개 도구**. 헤드리스 Chrome(CDP) 베타로 **479개 패널 전부 렌더(분석기 47종 빈 입력에서도 무크래시)·예외 0** 확인.
- **확정 버그 37건 수정**(8개 서브시스템 적대적 감사 → 코드 근거 검증). 대표:
  - 데이터 무결성: 같은 폴더 **아래로 드래그 재정렬 off-by-one**(바인더·코르크보드·아웃라이너 공통, `moveItem` 보정), **폴더 포함 병합 시 하위 문서 영구삭제** 차단, 폴더를 휴지통에 보낼 때 **하위 열린 문서 active/선택 정리**, 휴지통 직접 드롭 시 **원위치 복원 정보 보존**, 폴더→텍스트 변환 시 **자식 자동 그룹 해제**
  - 내보내기: **인라인 이미지가 DOCX/EPUB/ODT/Markdown/LaTeX/Fountain/FDX 에서 소실되던 문제**(이미지 보존/대체), **페이지 나눔**을 모든 포맷에 적용, ODT/LaTeX **중첩 목록** 보존, Markdown 빈 헤딩 제거, 한글에 붙은 **스마트 따옴표 짝짓기**(여는/닫는 교대)
  - 영속성: `.scriv` **자동저장이 인라인 미디어를 덮어쓰던 손실** 차단, Ctrl+S 가 폴더 피커를 다시 띄워 `.scriv` 중첩되던 문제, 다중탭 동기화가 **현재 뷰/네비를 리셋**하던 문제, `writeFileMap` 고아 파일 정리
  - 에디터/캔버스: 같은 문서를 **여러 곳에서 동시에 봐도 실시간 동기화**(자기-echo 가드)·읽기용 클릭의 허위 저장 차단, QuickRef 스크롤 리셋, **캔버스 파일 카드 인라인 편집**·**폴더 드롭 시 내부 파일 포함**·그룹 본문 마퀴 선택·휠 줌 페이지줌 방지
  - 접근성: IME 조합 중 ESC 가 모달을 닫던 문제, 모달 닫힘 시 다른 위젯 포커스 탈취 방지
  - **스크래치패드 자유 이동(드래그)·크기 조절·위치 영속화**

### 절차적 생성 + 작법서 기반 대규모 확장 (전수 베타·적대 감사)

국내외 유명·최신 작법서를 전수조사하고 절차적 생성 시스템을 더해 창작 스튜디오를 **약 2,445개 도구**로 확장했습니다.

- **작법서 기반 가이드 432종(18개 글쓰기 형식)** + **플롯/서사 구조 73종 추가**(시드 필드·맥키·요크 5막·보글러 여정 등) → 구조 총 91종. 형식별로 나브 그룹화.

세계의 글쓰기·비(非)글쓰기 앱을 조사해, **각각 거의 독립 앱 한 개 규모**의 도구 100종을 새로 구현했습니다(자잘한 추가가 아니라 큰 규모 지향). 전부 **무료·키 불필요·CORS 공개 API** 또는 **완전 로컬**이라 가입/비용 없이 동작합니다.

## 남은 한계

- 폴더 저장/열기·단일 RTF 선택은 Chromium 계열만 — 그 외는 ZIP/파일 입력 폴백

- 미디어 blob: 런타임은 IndexedDB 보관, 명시적 `.scriv`/zip 저장·자동 백업에는 인라인 포함(1.5초 폴더 자동저장은 텍스트만 — 같은 브라우저 재열기는 blob DB 로 동작)
- 코멘트는 지점(anchor) 기준(선택 범위는 형광펜으로 시각화)

- AI 키는 기본적으로 저장하지 않으며(세션 전용), 설정에서 "이 브라우저에 키 저장"을 켤 때만 localStorage 에 보관
